# 0004 — Beitragsarten

**Status:** gilt · 2026-10-10

| Art | Rhythmus | Länge | Quelle | Skill |
|---|---|---|---|---|
| Deep Dive | ~monatlich | 1.500–3.000 Wörter | eine geknackte Problemstellung | `deep-dive` |
| Build Log | wöchentlich | 200–500 Wörter | Commits der Woche | `build-log` |
| DIY | gelegentlich | frei | Fotos + Sprachnotiz | `diy-post` |

**Deep-Dive-Aufbau** (spielt die eigene Stärke aus — das Knacken, nicht das Weiterführen):
das Problem und warum es schwer aussah → die entscheidende Einsicht → wie es geknackt wurde →
was dabei schiefging → die Zahlen → was offen bleibt.

**Konsequenzen.** Das Schema erzwingt `type`; Projektseiten listen zugehörige Beiträge über
`project`. Keine weitere Art ohne neue Entscheidung.
