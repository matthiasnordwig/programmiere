# 0001 — Zweck, Publikum, Sprache

**Status:** gilt · 2026-10-10

**Kontext.** Die Projekte (Matrix, Plugin, Maintainer-Loop) sind stark, aber unsichtbar. Ziel
ist Gewicht und Sichtbarkeit ohne akademischen Weg: öffentliche, gründliche Texte, die die
Leute anziehen, die wirklich verstehen wollen. Der Blog soll als Nebenprodukt der Arbeit
entstehen, nicht als zusätzliche Arbeit.

**Entscheidung.** Englisch, für ein internationales technisches Publikum. Erzählt wird, *wie*
ein Problem geknackt wurde — die deduktive Einsicht, der Weg, was schiefging, die Zahlen.
Nicht: Produktmarketing, Tutorials für Einsteiger, Meinungsstücke ohne eigenes Ergebnis.

**Konsequenzen.** Repo-Doku bleibt Deutsch (Arbeitsprache), Seiteninhalt Englisch. Jeder
Beitrag braucht ein eigenes Ergebnis oder eine eigene Messung.
