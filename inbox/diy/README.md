# DIY-Eingang

Rohmaterial für DIY-Posts: Fotos und eine Sprachnotiz bzw. deren Transkript (`notes.md`), je
Projekt ein Unterordner, z. B. `inbox/diy/2026-10-rollladen/`. Bleibt lokal (gitignored).
Der Skill `diy-post` macht daraus einen Entwurf und übernimmt nur die Bilder, die der Post
wirklich verwendet, nach `src/assets/posts/<slug>/`.
